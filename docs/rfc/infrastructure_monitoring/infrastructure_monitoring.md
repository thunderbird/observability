# Infrastructure Monitoring

At Thunderbird, we define our infrastructure monitoring needs using the common framework of Service Level Agreements (SLAs), Service Level Objectives (SLOs), and Service Level Indicators (SLIs). This repo documents our approach alongside any tools and resources we use to implement this framework.
